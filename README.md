# Turner et al. — analysis pipeline

Scripts are numbered in the order they should be run.  

Put `behavior_sequences/` (the session CSVs plus `MANIFEST.csv`) alongside the
scripts and run from that directory.

| Step | Script | Reads | Writes |
|---|---|---|---|
| 01 | `01_compute_measures.R` | `behavior_sequences/` | `01_measures/` |
| 02 | `02_ACC_behavioral_batch_analysis.R` | `behavior_sequences/` | `02_transitions/` |
| 03 | `03_NestedPermutationTest.R` | `01_measures/` | `03_permutation/` |
| 04 | `04_NestedPermutationTest_GvS.R` | `01_measures/` | `04_permutation_GvS/` |
| 05 | `05_BehaviorTransition_BMI_vs_SAL.R` | `02_transitions/` | `05_transition_BMI_vs_SAL/` |
| 06 | `06_BehaviorTransition_GvS.R` | `02_transitions/` | `06_transition_GvS/` |
| 07 | `07_estimation_plots.R` | `01_measures/` | `07_plots_sulcus/`, `08_plots_gyrus/` |
| 08 | `08_estimation_plots_GvsS.R` | `01_measures/` | `08_plots_GvsS/` |
| 09 | `09_state_composition_plots.R` | `01_measures/` | `09_state_composition/ACCs/`, `.../ACCg/` |
| 10 | `10_MDE_estimation.R` | `01_measures/` | `10_MDE/` |

01 and 02 read the raw sequences files exported from BehaviorCloud. 
All other scripts read their outputs. 

## 01 — measures

Writes `measures.csv` (all sessions, every measure), `qc.csv`, and the three
analysis files: `ACCs_BMI.csv`, `ACCg_BMI.csv`, and `ACCgvss_BMI.csv`  

## 02 — transitions

Computes pro-social transitions and approach outcomes.
Writes `ACCs_transitions.xlsx` and `ACCg_transitions.xlsx`, each with `key_outputs`,
`behavioral_transition_counts`, `approach_outcomes` and `label_summary`.
Identity is pulled from `MANIFEST.csv`.

## 03 and 04 — permutation tests

03 - Main analysis in paper: 
writes `ACCs.csv`, `ACCg.csv` and `combined.csv`

04 - ACCs vs ACCg within animal.
BMI sessions only, hemisphere collapsed  
Not used in the manuscript; exploratory analysis as this was not a priori planned. 

## 07 to 10 — figures
Figures are named for the measure; the directory says which dataset.  

## 07 — estimation plots
Generates estimation plot figures for main figures

## 08 - estimation plots
Generates estimation plots for the exploratory analysis in Script 4

##09 - state composition plots
Generates flow histograms for state composition. 

## 10 — minimum detectable effect
Calculates minimum detectable effect at 80% power.  Note, run this last. It takes a while.
Writes `ACCs_results.csv` and `ACCg_results.csv` plus a progress log each.
